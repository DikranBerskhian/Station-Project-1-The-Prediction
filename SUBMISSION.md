# GitHub submission and peer reviews

## Submit your project

1. Create or fork the required GitHub repository; clone it locally.
2. Create a feature branch: `git switch -c station-project-1-tips`.
3. Copy this project into the repository, run the notebook, and check its outputs.
4. Run `git add .` and `git commit -m "Complete waiter tips prediction project"`.
5. Run `git push -u origin station-project-1-tips`.
6. On GitHub, open a pull request against the required base branch. Describe the dataset, pipeline, actual evaluation, and limitations from README.md.
7. Submit the real PR URL in the TUMO Labs form.

Do not claim the project has been pushed until these steps actually succeed. The attachment contains no destination repository.

## Review two assigned peers

Open each actual peer PR, clone its repository, check out the PR branch, install its requirements in a separate environment, and run the notebook from a fresh kernel. Assess data leakage, model suitability, valid scoring, reproducibility, code clarity, and documentation. Leave specific file/cell-based comments, including good work. Only approve after verifying; otherwise request concrete changes. Submit the real PR URLs and an honest top-level review.
